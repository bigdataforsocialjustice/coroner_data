# Topic modeling of child homicides using medical examiner data

This repository contains data and code for a project using Latent Dirichlet Allocation (LDA) topic modeling to analyze Medical Examiner cause-of-death narratives. 
The project explores how unstructured text from coroner reports can reveal underlying patterns in mortality—such as substance use, violence, trauma, and systemic neglect—that are often obscured in standard categorical data.

The analysis focuses on identifying latent themes across thousands of narratives and generating case-level topic proportions, which can be linked to neighborhood characteristics, demographic variables, or structural conditions. 
This work contributes to public health, social epidemiology, and data justice by demonstrating how machine learning can uncover the hidden narratives behind preventable deaths.

Key Features:
- Python script to automate downloading and processing the data
- Cleaned and preprocessed cause-of-death narrative data
- Text preprocessing scripts (tokenization, lemmatization, stopword removal)
- Implementation of LDA topic models in R

Outputs including top terms per topic and per-case topic distributions
The repository supports a broader initiative to translate environmental exposures into actionable legal insights.
